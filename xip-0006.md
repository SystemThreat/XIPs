## Abstract

xCoin mainnet began with block 0 at **2026-09-26 00:00:00 UTC**. This XIP
records the parameters it actually launched with and the result of mining
block 0, and replaces XIP-3, whose draft still described the earlier 21M XCF
schedule and a September 30 date. Every value below is read from the public
source at tag `mainnet-genesis-2026-09-26` of
[SystemThreat/xCoin](https://github.com/SystemThreat/xCoin)
(`src/kernel/chainparams.cpp`, `src/consensus/params.h`), and every node
verifies them itself at startup.

`EMISSION_TABLE` (XIP-5).

## The ceremony, as it ran

1. **Date.** Genesis was planned for September 30, then moved to make room
   for HX1 (XIP-4), and in the end mined early, on 2026-09-26 00:00 UTC, once
   HX1 was merged. The time was announced with a countdown on superknet.com.
2. **Rehearsals.** Testnet A ran the network for weeks before genesis and is
   now retired (ledger archived at height 3,555). A second, short rehearsal
   chain was stopped at height 786, before it reached coinbase maturity; the
   spend-after-maturity step of XIP-3's dress rehearsal was therefore not
   completed on that chain.
3. **Mining block 0.** `xcoin-genesis` built the charter genesis at T and
   mined it to 0x1e0fffff; the output is the table above.
4. **Freeze.** The `FINAL_GENESIS_*` constants and `GENESIS_IS_FINAL = true`
   were committed (the node refuses to compile a final genesis with a
   provisional emission table) and tagged `mainnet-genesis-2026-09-26` on the
   public repository.
5. **Release.** Still to do: a GitHub release with binaries and their SHA-256
   sums on three surfaces (the release page, xcoinproject.com, superknet.com),
   as XIP-3 required. Until then, build from the tag and compare the genesis
   hash your node prints with the one above.

## Activation (Consensus only)

Chain: mainnet. Mechanism: genesis rule. Deployed 2026-09-26: block 0 mined,
the network running on a five-country operator fleet (New York, Hong Kong,
London, Singapore, São Paulo) with every node reporting `genesis_is_final`,
the charter hash and the currency id above.

## Security considerations

The threat is substitution: a different genesis presented as the real one.
The genesis hash, charter hash and currency id are fixed in public source, a
node built from any other values will not connect to this chain, and they
appear on independent surfaces (this repository, the source repository,
superknet.com). The binary release with published checksums (step 5) is still
outstanding; until it exists, trust rests on building from source.
