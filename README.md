# XIPs — xCoin Improvement Proposals

The public, numbered record of decisions about the xCoin network: the
post-quantum proof-of-work chain (ML-DSA-65 / SLH-DSA signatures, MetalDAG,
21M cap) whose mainnet genesis is **September 30, 2026**.

Every meaningful decision gets a number here — consensus rules that could
fork the chain, policies of the official software, the workings of the
project itself — so that "why is it like this?" always has a citable answer.

| XIP | Title | Type | Status |
|----:|-------|------|--------|
| [1](xip-0001.md) | The XIP Process | Process | Active |
| [2](xip-0002.md) | The Own-Node Pool Rule | Policy | Active |
| [3](xip-0003.md) | Mainnet Genesis Parameters and Ceremony | Consensus | Draft |

**Propose one:** copy [`xip-template.md`](xip-template.md), post it for
discussion on [minedifferent.com/c/protocol](https://minedifferent.com/c/protocol)
— where every account is an ML-DSA-65 signature — and open a pull request.
The process itself, including who decides and how that changes as the
network grows, is [XIP-1](xip-0001.md).
